Method

implied value = TVL × category multiple × growth adjustment × age adjustment

Rounded to the nearest dollar, with a $1 floor. Every input comes from the sealed snapshot.

Coverage, not a model input. The sealed snapshot is one fixed file, the same bytes every entrant works from. Its $50M figure is the snapshot's own coverage floor, not a model parameter; this board ranks every protocol in the snapshot that records no token and passes the four screens below.

Category multiple
Median market-cap ÷ TVL among protocols in the same category that already trade. Fewer than 3 samples → global median. Clamped to 0.05–20.
Growth adjustment
1 + clamp(7d change, −30, +30) ÷ 100 × 0.5. A +30% week adds 15%, a −30% week subtracts 15%; a missing change counts as 0.
Age adjustment
1 + 0.2 × min(1, log10(1 + days ÷ 30) ÷ log10(13)). Longer tokenless operation scores higher, capped at +20% and reached at 360 days.
Eligibility screens
Four screens run in order and the first match sets a protocol aside. CATEGORY_DERIVATIVE reads the category field for a derivative venue (CEX, liquid staking/restaking, bridges). PRODUCT_FORM reads the name for a wrapped or staked product form. TOKEN_LINEAGE matches a version-stripped name to a protocol that records a token in this snapshot. EXCHANGE_BRAND matches an exchange-brand prefix — external common knowledge, the only screen not derived from the snapshot.

Every row records no token in this snapshot: neither a CoinGecko id nor a ticker. That is a snapshot fact, not a claim about a project's history or plans.
